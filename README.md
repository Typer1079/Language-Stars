# Read Aloud Stars

Kids reading practice (Levels 1–5) and adult English → Spanish speaking practice (Levels ES1–ES6),
with stars, a sticker shop and a sticker canvas.

Hosted with GitHub Pages: Settings → Pages → Deploy from branch → `main` / root.

- `index.html` — the whole app (HTML + Tailwind CDN + vanilla JS)
- `manifest.webmanifest`, `icons/` — "Add to Home Screen" support
- Progress is saved in each browser; use ⬇️ Save / 📂 Upload to move a backup between devices.
- Microphone needs HTTPS (GitHub Pages provides it) and Chrome, Edge or Safari.
